# Xin Zhang — Academic Portfolio

Personal academic portfolio of Xin Zhang, focused on Human–Computer Interaction, VR/XR, eye tracking, digital health, and healthy ageing.

## Structure

- `index.html` — Home
- `research/` — Research overview
- `projects/` — Selected projects and case studies
- `publications/` — Publications
- `about/` — About
- `assets/` — CSS, JavaScript, and images

## Deployment

This is a static HTML/CSS/JavaScript site. No framework or package installation is required.

For Cloudflare Pages:
- Production branch: `main`
- Framework preset: `None`
- Build command: `exit 0` (or leave blank)
- Build output directory: `/`
- Root directory: leave blank
